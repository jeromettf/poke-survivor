# 관동 원정기

파트너 포켓몬 한 마리를 키워 야생 포켓몬 무리를 뚫고, 지역 북쪽 체육관에서 보스를 쓰러뜨리는 뱀서라이크 팬 게임입니다. HTML 파일 하나로 돌아가고, 모바일 세로 화면 기준으로 만들었습니다.

플레이: https://jeromettf.github.io/poke-survivor/

## 조작
- 화면을 누르고 끌면 이동합니다. 공격은 자동입니다.
- 게이지가 차면 오른쪽 아래 버튼으로 궁극기를 씁니다.
- PC: WASD 또는 방향키로 이동, 스페이스로 궁극기, Esc로 일시정지

## 구성
- 파트너 6종(파이리, 꼬부기, 이상해씨, 피카츄, 고오스, 미뇽)과 파트너별 전용 기술 6~7개
- 기술 Lv.5와 짝이 되는 지닌 물건을 모으면 보물상자에서 기술 진화
- 레벨업 카드의 다시 뽑기, 봉인, 건너뛰기
- 지역마다 북쪽 체육관이 목적지. 원 안에 들어가 도전하면 보스전, 7분이 지나면 야생 포켓몬이 폭주
- 적 행동 6종(원거리, 돌진, 자폭, 유령, 비행, 탱커), 2분 30초와 5분의 중간보스
- 맵의 사당 4곳에서 축복 선택, 보스 처치 후 무한 모드
- 지역 8곳. 체육관 보스를 이기면 배지(영구 혜택)를 얻고, 클리어한 지역은 도전 단계 ★1~3이 열림
- 처음 쓰러뜨린 종은 도감에 등록되어 위력 보너스
- 파트너 해금: 피카츄(상록숲 클리어), 고오스(도감 20종), 미뇽(배지 4개)
- 코인으로 영구 강화
