# 관동 원정기

포켓몬 팬 게임입니다. 두 가지 모드가 있습니다.

- 원정 모드: 파트너 한 마리를 키워 야생 포켓몬 무리를 뚫고 지역 북쪽 체육관의 보스를 쓰러뜨리는 뱀서라이크
- 배틀 아레나: 3대3 봇 대전. 두 라인과 정글이 있는 맵에서 포탑을 부수고 적 넥서스를 파괴하면 승리

HTML 파일 하나로 돌아가고, 모바일 세로 화면 기준으로 만들었습니다.

플레이: https://jeromettf.github.io/poke-survivor/

## 조작 (원정 모드)
- 화면을 누르고 끌면 이동합니다. 공격은 자동입니다.
- 회피 버튼으로 짧게 구르며 잠깐 무적이 됩니다(재사용 2.6초).
- 게이지가 차면 오른쪽 아래 버튼으로 궁극기를 씁니다.
- PC: WASD 또는 방향키로 이동, Shift로 회피, 스페이스로 궁극기, Esc로 일시정지

## 조작 (배틀 아레나)
- 화면을 누르고 끌면 이동합니다. 멈춰 서면 사거리 안의 미니언과 야생 포켓몬을 자동으로 공격합니다.
- 공격 버튼을 누르고 있으면 적 포켓몬을 먼저 노리고 쫓아갑니다.
- 스킬 버튼을 짧게 누르면 가까운 적에게 바로 쓰고, 누른 채 끌면 방향과 거리를 조준합니다.
- 상점은 본진에 있거나 쓰러져 있을 때 열립니다. 귀환 버튼은 4.5초 뒤 본진으로 돌아갑니다.
- PC: WASD 또는 방향키로 이동, 스페이스로 공격, J·K·L·; 또는 1~4로 스킬(마우스 방향 조준), B 귀환, P 상점, Esc 일시정지

## 배틀 아레나 구성
- 세로로 긴 맵에 왼쪽·오른쪽 라인과 가운데 정글, 강 중앙의 잠만보. 정글은 나무와 바위 벽으로 캠프마다 공간이 나뉨
- 풀숲 16곳: 안에 들어가면 적에게 보이지 않고, 공격하거나 스킬을 쓰면 잠깐 드러남
- 강의 제단 2곳: 5초 동안 혼자 서 있으면 점령(1분 30초부터, 점령 후 60초 잠김). 제단 하나마다 팀 피해 +6%, 초당 회복 +3
- 오랭열매 덤불 8곳: 밟으면 체력 회복, 75초 뒤 다시 열림
- 라인마다 바깥·안쪽 포탑, 본진에 넥서스 포탑과 넥서스. 앞 포탑을 부숴야 다음 포탑을 공격할 수 있음
- 미니언 30초마다 출발(근접 3, 원거리 2, 세 번째 웨이브마다 대포). 안쪽 포탑이 무너진 라인에는 강화 미니언
- 정글 캠프 5종(붉은 기운, 푸른 기운 버프 포함)과 잠만보(팀 전체 2분 강화)
- 포켓몬 6종의 스킬 3개와 궁극기(Lv.5), Lv.5·9 진화, 타입 상성 반영
- 아이템: 재료 6종을 2개씩 조합하는 완성 아이템 12종(기합의띠, 울퉁불퉁멧, 빛의점토 등 고유 효과 포함). 완성 아이템은 골드를 내고 능력치 1.5배로 강화, 판매 가능, 최대 6칸
- 맡을 자리(왼쪽 라인, 정글, 오른쪽 라인)와 적 봇 난이도 3단계
- 봇은 막타, 귀환, 교전 판단, 정글 순회와 기습, 잠만보 사냥, 후반 집결과 본진 수비를 스스로 판단
- 12분부터 포탑과 넥서스가 점점 약해져 한 판이 대체로 15분 안팎에 끝남
- 결과 화면(K/D/A, CS, 아이템, MVP)과 전적 기록, 도전과제 4종 추가

## 원정 모드 구성
- 파트너 6종(파이리, 꼬부기, 이상해씨, 피카츄, 고오스, 미뇽)과 파트너별 전용 기술 6~7개
- 기술 Lv.5와 짝이 되는 지닌 물건을 모으면 보물상자에서 기술 진화
- 레벨업 카드의 다시 뽑기, 봉인, 건너뛰기
- 지역마다 북쪽 체육관이 목적지. 원 안에 들어가 도전하면 보스전, 7분이 지나면 야생 포켓몬이 폭주
- 적 행동 6종(원거리, 돌진, 자폭, 유령, 비행, 탱커), 2분 30초와 5분의 중간보스
- 체육관으로 이어지는 길, 연못, 부술 수 있는 상자·덤불(코인·열매·보물상자), 미니맵
- 엘리트 특성 4종(신속한, 단단한, 분노한, 대장), 보스 낙하 장판·나선 탄막과 체력 50% 분노 페이즈
- 맵의 사당 4곳에서 축복 선택, 보스 처치 후 무한 모드
- 도전과제 23종(아레나 4종 포함)과 코인 보상
- 작곡한 배경음 9곡(타이틀, 필드 4곡을 지역별 조로 변주, 보스, 리그, 리그 보스, 엔딩), 볼륨 조절, 진동, 세이브 코드 내보내기/가져오기
- 지역 8곳과 최종 지역 포켓몬리그(사천왕 4연전과 챔피언, 클리어 시 엔딩과 명예의 전당). 체육관 보스를 이기면 배지(영구 혜택)를 얻고, 클리어한 지역은 도전 단계 ★1~3이 열림
- 처음 쓰러뜨린 종은 도감에 등록되어 위력 보너스
- 파트너 해금: 피카츄(상록숲 클리어), 고오스(도감 20종), 미뇽(배지 4개)
- 코인으로 영구 강화
